# 🧮 Desafio 1: Calculadora Básica em Python

Aplicação de terminal desenvolvida em Python para praticar lógica de programação, funções e controle de fluxo através das quatro operações matemáticas fundamentais.

---

## 🎯 Objetivo do Desafio
Construir uma calculadora funcional executada no terminal, praticando os conceitos essenciais da linguagem Python:
- Criação de funções modulares para cada operação (`def`).
- Coleta de entradas do usuário e conversão de tipos (`input` e `float`).
- Tratamento condicional para seleção de opções (`if`, `elif`, `else`).
- Prevenção de exceções e erros matemáticos (divisão por zero).

---

## 🚀 Como Executar

```bash
python calculadora.py
```

---

## 💻 Exemplo de Execução
```text
=== CALCULADORA SIMPLES ===
Escolha uma operação:
1 - Adição (+)
2 - Subtração (-)
3 - Multiplicação (*)
4 - Divisão (/)
Digite o número da operação (1/2/3/4): 1

Digite o primeiro número: 25
Digite o segundo número: 10

Resultado: 25.0 + 10.0 = 35.0
```
